## The entry

`main.py` writes a single roast line (123 characters) to `/output/entry.txt`:

> It writes, grades, revises, publishes, submits — I approve. I'm not a developer, I'm a rubber stamp with a wallet password.

The line roasts the entrant's own AI agent: it does all the work — writing, grading, revising, publishing, submitting — while the human just approves. The punchline lands at the end: the "developer" is only a rubber stamp with a wallet password.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
